# web-parser

Автоматический сборщик proxy URI из доступных подписок/API, которые возвращают конфиги текстом или в Base64. Результат публикуется в `configs.txt`; основная LIKVID VPN сможет забирать его по RAW-ссылке.

## Как настроить

1. Откройте `sources.json`.
2. Замените примерный URL настоящим URL подписки или API endpoint, который возвращает её содержимое.
3. Оставьте `mode: "direct"`, если источник принимает прямой HTTP-запрос. В `user_agent` можно указать UA клиента, а в `headers` — дополнительные заголовки, если они нужны и у вас есть право доступа к источнику.
4. Для источников, поддерживающих path-style прокси p.kfwl.lol, установите `mode: "p_kfwl"`; доступны `user_agent`, `os`, `hwid` и `proxy_base`. Совместимость этой схемы нужно проверить на конкретном источнике: сервис/источник может поменять формат или не поддерживать такую выдачу.
5. Сохраните изменения в ветке `main` и откройте **Actions → Update web subscription configs → Run workflow** для первого запуска.

Допустимо также добавить прямые URL по одному на строку в `sources.txt`. Если заполнены источники в `sources.json`, этот файл используется как запасной список только тогда, когда настроенных источников в JSON нет.

## Важное ограничение

HTML-страница веб-интерфейса сама по себе обычно не содержит конфигов. Если ответ — обычный HTML и внутри нет proxy URI, надо указать реальный API/endpoint подписки, который клиент запрашивает в фоне, либо использовать поддерживаемый декодер. Парсер не пытается обходить CAPTCHA, авторизацию или другие механизмы доступа. Не добавляйте чужие приватные подписки без разрешения.

## Результат

После успешного запуска конфиги (по одному на строку, дубликаты удаляются) будут находиться по адресу:

`https://raw.githubusercontent.com/cheesyx-rudy/web-parser/main/configs.txt`

В Actions у репозитория должно быть разрешение **Read and write permissions** для `GITHUB_TOKEN`, чтобы workflow мог коммитить изменившийся `configs.txt`.

## Проверка локально

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python main.py
```

В логах не печатаются полные URL с query-токенами или авторизационные заголовки.
